# Seguridad y evidencia de MFA

Auth usa OAuth 2.0 con Google, parámetros de sesión `client_state/client_port`, callback al loopback de Godot y emisión de JWT RSA con `sub,email,iat,exp`. Los access tokens duran 15 minutos. Refresh se almacena en PostgreSQL durante 30 días; logout revoca el refresh indicado y los accesos ya emitidos siguen vigentes hasta expirar. Gateway, Auth, Lobby y Game validan la firma con PEM público; Game comprueba sujeto y expiración explícitamente, aplica membresía y verifica expiración en WebSocket. Lobby verifica JWT con PyJWT y no exige explícitamente todos los claims. La validación exacta se conserva en este corte. La autorización interna Lobby → Game usa un secreto separado.

**No hay evidencia de MFA exigida por el sistema.** Una cuenta Google puede tener verificación en dos pasos, pero el backend no comprueba que se haya usado, no exige una política de grupo administrado y no tiene otro desafío. No se trata la firma del JWT, el refresh, `state` o PKCE como un segundo factor. [Documentación oficial de Google OIDC](https://developers.google.com/identity/openid-connect/openid-connect).

Opciones para completar el requisito: usar un proveedor/política que permita exigir y verificar el nivel de autenticación para todas las cuentas admitidas, o añadir enrolamiento y desafío de segundo factor antes de emitir tokens en un flujo coordinado con Godot. Hay que probar rechazo sin segundo factor y éxito con ambos, además de recuperación, revocación y seguridad de las credenciales. No se habilitó un nuevo requisito de login sin ese trabajo; las pruebas de OAuth de este corte no verifican el segundo factor ni realizan el intercambio real con Google.

Métricas: cabecera `X-Metrics-Key` y clave aleatoria separada, mínimo 32 caracteres. Grafana exige autenticación; Prometheus y Grafana se enlazan solo a loopback por defecto. Los puertos de datos expuestos en el Compose de desarrollo requieren red privada en un despliegue real. No compartir claves privadas, parámetros con tokens, registros de headers ni salidas completas de configuración.
