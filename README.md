# PixelChiss Server

Servidor backend para un videojuego multijugador desarrollado mediante una arquitectura basada en microservicios.

## Arquitectura

El proyecto estará compuesto por:

- API Gateway
- Eureka Service Registry
- Auth Service
- Player Service
- Lobby Service
- Game Service
- Log Aggregator

## Tecnologías

- Java
- Kotlin
- Python
- Spring Boot
- Spring Cloud
- FastAPI
- PostgreSQL
- MongoDB
- Redis
- Docker
- Docker Compose
- Swagger / OpenAPI
- WebSocket
